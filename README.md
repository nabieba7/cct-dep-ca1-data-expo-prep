# cct-dep-ca1-data-expo-prep
# Population and Society: Analysis of the Adult Dataset

In this study, R will be used to analyse education, occupation,
and earnings in an historical adult US population.

## Research question

What is the variation in the fraction of those that earn more than
$50,000 annually based on educational background, age group, number
of hours worked each week and recorded gender in the US Adult population?

## Objectives

- Examine and clean the data set.
- Analyse trends using descriptive statistics and graphical analysis.
- Encode categorical variables and transform the data.
- Contrast numeric PCA with numeric & encoded PCA.
- Discuss results and limitations.

## Data Set

Adult data set is an extract from the 1994 US Census database.
Together, the training and test datasets have 48,842 rows
and 15 columns before cleaning.

Original source: https://archive.ics.uci.edu/dataset/2/adult

Kaggle copy: https://www.kaggle.com/datasets/uciml/adult-census-income

The analysis describes this historical sample, not today's population.
